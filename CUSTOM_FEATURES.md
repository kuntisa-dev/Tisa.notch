# Tisa Dynamic Island: custom features (based on Boring Notch)

Based on Boring Notch 2.7.3 (build 271) by TheBoredTeam. Seven features added; all new code is in `TisaDynamicIsland/features/`.

## Build and run

1. Xcode 26 or later (the README asks for macOS 15.6+ to build; the app itself runs on macOS 14+).
2. Open `TisaDynamicIsland.xcodeproj` and wait for Swift packages to resolve.
3. Signing & Capabilities: set your Apple ID as Team for the **TisaDynamicIsland** and **TisaDynamicIslandXPCHelper** targets.
4. Quit Boring Notch and any older Tisa Notch build, and turn off their "Launch at login" (otherwise two notches run on top of each other), then press ⌘R.

Builds cleanly with Xcode 26.2 (checked unsigned with `xcodebuild -scheme TisaDynamicIsland CODE_SIGNING_ALLOWED=NO build`).

## Staying light in the background

- The Settings and Fan Studio windows let go of their views when closed (a closed window that is kept around still redraws on every sensor reading) and rebuild them when opened.
- Sensors are read every 5 s while nothing shows them (notch closed, both windows closed) and macOS is driving the fans; at the chosen polling interval as soon as the notch or a window opens, or whenever the app controls a fan (`FanEnvironment.setWatching`).
- At launch, music helper scripts left without an owner by a force-quit copy are stopped.

## Permissions

- **Downloads folder**: new sandbox entitlement `com.apple.security.files.downloads.read-only`.
- **Microphone**: new entitlement `com.apple.security.device.audio-input` and `NSMicrophoneUsageDescription`, in case macOS asks before changing the mute state.
- **Pictures folder**: new entitlement `com.apple.security.assets.pictures.read-write`, so Photo Booth can save to ~/Pictures. The camera permission already existed for the mirror.
- **Screen & System Audio Recording**: only for the audio visualizer. macOS shows its recording indicator while it listens. Restart the app after granting it.

## Other changes

- Renamed from Boring Notch / Tisa Notch to Tisa Dynamic Island: project `TisaDynamicIsland.xcodeproj`, source folder `TisaDynamicIsland/`, helper `TisaDynamicIslandXPCHelper/`, and `Boring*` types to `Tisa*` (e.g. `TisaViewModel`, `TisaViewCoordinator`). Links to the original project on GitHub stay, with a "Based on Boring Notch" credit in About and on the welcome screen.
- Bundle ID is `com.kuntisa.tisadynamicisland` (helper: `com.kuntisa.tisadynamicisland.TisaDynamicIslandXPCHelper`), and the app is named "Tisa Dynamic Island", so it installs next to the official app instead of replacing it. It starts with fresh settings and asks for permissions again. The helper's XPC service name now follows the app's bundle ID automatically.
- Automatic update checks are off (`SUEnableAutomaticChecks = false`), so Sparkle won't replace this build with the official one. Don't use "Check for Updates" unless you want the official version back.
- The unused clipboard and microphone shortcut defaults (⇧⌘C, fn-F5) changed to ⌃⌥V and ⌃⌥M, because ⇧⌘C clashes with Chrome and Finder and fn-F5 can't be registered as a global hotkey.
- The microphone HUD shows even when "Replace system HUD" is off.
- Photo Booth runs the camera only while its tab is visible. Opened with ⌃⌥P it closes itself after 30 s unless the pointer is over the notch; a countdown keeps it open. It also stops the Home tab's mirror while in use.
- Tab icons now show their name on hover.

## Not yet tested on a Mac

- Muting uses the input device's mute switch, or input volume 0 if it has none. Some USB or Bluetooth mics may expose neither; you'll hear a beep then.
- Safari's download progress reads `DownloadEntryProgressBytesSoFar` / `DownloadEntryProgressTotalToLoad` from the `.download` bundle's Info.plist. If a Safari version stops writing those, progress falls back to a spinner.
- Photo Booth's shutter sound looks for macOS's `Shutter.aif` / `Grab.aif` system sounds and falls back to "Tink" if neither exists.
- Khmer calendar: typing a note makes the notch take the keyboard while the editor is open (`NotchTyping`); check typing with the ABC and Khmer keyboards, that the notch stays open while you type, and that a note with Alert shows a notification at its time. Compare a month or two with a printed Khmer calendar.
- Routines: make one 2 minutes ahead and check the notch drops down and stays; Snooze comes back after 10 minutes; Done raises the streak; quit the app before a routine and check the backup banner 1 minute after, and that Done in the banner ticks it.
- The audio visualizer uses ScreenCaptureKit from the sandboxed app. If capture fails, the bars fall back to random motion and Xcode's console shows `SystemAudioAnalyzer: could not start capture`.

## Files

Everything added for Tisa lives in `TisaDynamicIsland/features/`, one folder per feature. Xcode picks up files in that folder by itself, so new files only need to be saved there. The other folders under `TisaDynamicIsland/` (`components/`, `managers/`, `models/` and so on) keep Boring Notch's layout, so its updates can still be merged.
